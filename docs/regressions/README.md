# Regressions

This directory tracks historical regressions, providing a permanent record of what broke, why it broke, and how it was resolved.

## Regression Log Format
When logging a regression, use the following structure:

### [Issue Title / Date]
- **Previously Broken Behavior:** *(What specifically failed?)*
- **Root Cause:** *(Why did it fail?)*
- **Fix:** *(How was it resolved? Link to PR/Commit)*
- **Tests Added:** *(What test was added to prevent recurrence?)*
